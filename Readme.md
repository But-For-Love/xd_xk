# 西电自动选课工具

> 帮你自动选课、退课、抢课的小工具。**不用懂代码，双击就能用。**

---

## 📌 这是什么？

选课系统开放时，热门课几秒钟就被抢光。这个工具可以帮你：

- **自动选课** — 填好课程号，点一下按钮，工具帮你反复提交直到选上
- **自动退课** — 不想上的课，一键退掉
- **容量检查** — 盯住某门课，一旦有人退课立刻帮你抢
- **捡漏模式** — 扫描所有课程，见空位就抢（抢别人退掉的课）

## 🚀 三步开始（最简单的方式）

### 第一步：下载

去 [Releases 页面](https://github.com/But-For-Love/xd_xk/releases) 下载最新的 `西电自动选课工具.exe`。

> ⚠️ 浏览器可能会提示"此文件可能危害计算机"，点击「保留」或「仍要下载」即可。这是正常现象，所有 exe 文件都会有这个提示。

### 第二步：打开

1. 下载完成后，双击 `西电自动选课工具.exe`
2. Windows 可能会弹出「Windows 已保护你的电脑」（SmartScreen 拦截）
3. 点击 **「更多信息」**，然后点 **「仍要运行」**

> 为什么会被拦截？因为这个 exe 没有花钱买微软的代码签名证书（每年几千块）。只要你是从本仓库的 Releases 下载的，就是安全的。

## 📖 各功能详解

### 🟢 选课

1. 在「选课池」里添加你要选的课程（课程号 + 课序号）
2. 勾选「连续重试」—— 如果课满了，工具会不停重试，直到有人退课
3. 点「选　课」按钮
4. 观察黑底日志区域，看到「操作成功」就是选上了

### 🔴 退课

1. 在「选课池」里添加你想退的课程
2. 点「退　课」按钮
3. 看到「操作成功」就退掉了

### 🟡 容量检查

盯住特定课程，一旦人数没满就立刻帮你选上。

1. 在「选课池」里添加想抢的课程
2. 点「容量检查」按钮
3. 工具每 0.5 秒检查一次，有空位自动选课
4. 点「■ 停止」可以随时停

### 🎯 捡漏模式

扫描**所有课程**（不只是你添加的），见空位就抢。适合没有具体目标、有什么课就上什么课的情况。

1. 选「必修」或「选修」
2. 点「捡漏」
3. 工具每 5~10 秒扫描一轮

### 📋 浏览课程

想看学校开了哪些课？点「浏览课程」，工具会从服务器拉取完整的课程列表，你可以搜索、过滤、勾选后添加到选课池。

> 💡 点「⚡ 添加未满课程」可以直接只看还有名额的课。

## ⚙️ 什么是「自动验证码」？

选课系统登录时需要输入验证码。工具提供两种方式：

| 方式 | 设置 | 说明 |
|------|------|------|
| 自动识别 | ☑ 勾选「自动验证码」 | 工具用 AI 自动识别，大部分时候好用 |
| 手动输入 | ☐ 不勾选 | 弹出一张验证码图片，你用眼睛看，手动输入 |

推荐先尝试自动识别。如果总是登录失败，取消勾选改用人工输入。

## ❓ 常见问题

### 登录失败怎么办？

1. 检查学号和密码有没有输错
2. 确认你**在校园网环境下**（宿舍校园网、图书馆 WiFi 或者连了 VPN）
3. 试试取消「自动验证码」，手动输入验证码
4. 检查「选课批次」是否正确 —— 点「获取批次」按钮可以看到当前有哪些批次可选

### 连不上服务器？

选课系统 `xk.xidian.edu.cn` **只能在校园网内访问**。如果你在校外：
- 连学校 VPN（EasyConnect 或 aTrust）
- 或者等回学校再用

### 为什么一直显示"所选课程人数已满"？

课确实满了。你可以：
- 勾选「连续重试」，工具会不停帮你重试，等有人退课就自动选上
- 或者用「容量检查」盯住这门课

### 课程号和课序号是什么？在哪看？

- **课程号**：例如 `TE204003`，在选课系统里每门课都有的编号
- **课序号**：例如 `02`，同一门课可能开好几个班，课序号区分不同班级。在你课程表小卡片左上角的 `[01]`、`[02]` 就是课序号

> ⚠️ 必修课**必须填课序号**，选修课可以不填。

### 工具安全吗？会不会泄露我的密码？

- 密码只在你的电脑上运行，只发送给学校选课服务器
- **不会**上传到任何第三方服务器
- 代码完全开源，你可以自己查看：`xd_xk/encrypt.py`（密码加密）、`xd_xk/core.py`（网络请求）
- 如果还不放心，用完改密码即可

### 关掉工具后需要重新填信息吗？

不需要。工具关闭时会自动保存你填的学号、密码和课程列表到 `conf.json` 文件，下次打开会自动填好。

## 👨‍💻 进阶：命令行模式（给会用命令行的同学）

如果你习惯用命令行，也可以用 `uv run xd-xk` 来操作：

```bash
# 选课（必修）
uv run xd-xk select

# 选课（选修）
uv run xd-xk select -c 1

# 退课（选修）
uv run xd-xk drop -c 1

# 容量检查（盯特定课程）
uv run xd-xk check TE204003 TE204004

# 容量检查（使用默认课程号列表）
uv run xd-xk check

# 查看完整帮助
uv run xd-xk --help
```

> 命令行模式也需要 `conf.json` 配置文件，格式见下方。

### 配置文件格式

```json
{
  "ocr_captcha": "1",
  "debug": "0",
  "batch_name": "第二轮补选（国际创新周）",
  "bx_or_xx": 0,
  "bx": [{ "KCH": "TE204003", "KXH": "02", "KCM": "大学语文" }],
  "xx": [{ "KCH": "FL006066", "KXH": "", "KCM": "英语选修" }],
  "data": {
    "loginname": "你的学号",
    "password": "你的密码",
    "captcha": "xxxx",
    "uuid": "xxxx"
  }
}
```

| 字段 | 说明 |
|------|------|
| `ocr_captcha` | `"1"` = AI 自动识别验证码，`"0"` = 手动输入 |
| `debug` | `"1"` = 把服务器返回的数据保存到文件（出问题时调试用） |
| `batch_name` | 选课批次的关键词，用于匹配当前是哪个选课阶段 |
| `bx` | 必修课列表，**必须同时填 KCH 和 KXH** |
| `xx` | 选修课列表，只需要 KCH |

### 从源码安装

```bash
# 1. 安装 Python 3.12+ https://www.python.org/downloads/
# 2. 安装 uv https://docs.astral.sh/uv/
# 3. 克隆项目
git clone https://github.com/But-For-Love/xd_xk.git
cd xd_xk

# 4. 安装依赖
uv sync

# 5. 运行 GUI
uv run xd-xk-gui

# 6. 或运行 CLI
uv run xd-xk --help
```

## 📦 项目结构

```
xd_xk/
├── pyproject.toml          # 项目配置
├── build.py                # 打包 exe 的脚本
├── conf.example.json       # 配置文件模板
└── xd_xk/
    ├── core.py             # 核心功能：登录、选课、退课
    ├── encrypt.py          # 密码加密（AES）
    ├── gui.py              # 图形界面
    └── cli.py              # 命令行界面
```
